# خانه‌دار – اپ اندروید

داده‌ها در حافظهٔ داخلی خود اپ (WebView localStorage) ذخیره می‌شوند و بدون اینترنت کار می‌کند.

## راه ۱: GitHub Actions (بدون نصب چیزی)
1. یک مخزن خصوصی بساز و محتوای این پوشه را در آن بگذار (push).
2. تب Actions ← «Build APK» ← Run workflow.
3. پس از پایان، فایل `khanedar-apk` را از Artifacts دانلود کن (داخلش app-debug.apk است).
4. روی گوشی نصب کن (اجازهٔ «نصب از منابع ناشناس» لازم است).

## راه ۲: روی کامپیوتر خودت
با Node 18+، JDK 17 و Android SDK: `bash build.sh`

## نکته
با حذف اپ، داده‌ها پاک می‌شوند؛ پیش از آن از «پشتیبان» داخل تنظیمات برنامه نسخه بگیر.
